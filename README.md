🛍️ React E-Commerce Store

A modern and responsive e-commerce web application built with React. This project provides an interactive shopping experience where users can browse products, explore categories, view product details, manage their shopping cart, and save their favorite products.

🌐 Live Demo

"View Live Website" (https://react-ecommerce-store-lilac.vercel.app/)

📸 About the Project

This project was developed to practice and improve my frontend development skills using React and modern JavaScript. It includes reusable components, client-side routing, API integration, and state management for shopping cart and favorite products.

✨ Features

- Product Browsing: Display products fetched from an external API.
- Category Navigation: Browse products by category.
- Product Details: View individual product information.
- Shopping Cart: Add and remove products and view the order summary.
- Favorites: Save and remove favorite products.
- Interactive Notifications: Display feedback when adding products to the cart.
- Hero Slider: Showcase featured content using an interactive image slider.
- Responsive UI: Styled components for a clean shopping experience.
- Persistent Storage: Preserve cart and favorite data using local storage.

⚙️ Installation and Setup

To run this project locally:

1. Clone the repository:

   git clone https://github.com/lenasalah937-beep/react-ecommerce-store.git

2. Navigate to the project directory:

   cd react-ecommerce-store

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal.
